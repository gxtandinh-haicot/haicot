Quản lý dữ liệu

Trang này chỉ xử lý file trên máy của Cha, không gửi dữ liệu đi đâu. Kết quả là một file data.json để tải lên trang web. Số điện thoại được che 3 số cuối trước khi xuất file.

1Thanh tiêu đề

2Dữ liệu từ file Excel

Cột nhận được: STT · MÃ SỐ · NGƯỜI ĐÃ KHUẤT (gồm tên thánh) · NGÀY SINH · NGÀY MẤT · LIÊN HỆ · SỐ ĐIỆN THOẠI · ĐỊA CHỈ. Nạp file mới sẽ thay toàn bộ danh sách cũ.

Xóa toàn bộ người khỏi danh sách? File data.json xuất ra sẽ không còn ai. Tiêu đề được giữ nguyên.

3Xuất file và đưa lên trang web

  1. Vào kho GitHub của trang web, bấm Add file → Upload files.
  2. Kéo file data.json vừa tải vào (ghi đè file cũ), bấm Commit changes.
  3. Chờ 1–2 phút rồi mở trang tra cứu để kiểm tra.
